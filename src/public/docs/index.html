🚀 Getting Started

Welcome to the Shipex API! This guide will help you integrate our shipping platform into your application.

Authentication

All API requests require authentication using an API key. You can generate an API key from your dashboard.

curl -X GET https://api.shipex.com/api/v1/orders \ -H "X-API-Key: your-api-key-here"

Base URL

All API endpoints are relative to:

https://api.shipex.com/api/v1

Rate Limiting

API requests are rate-limited based on your subscription plan:

FREE Plan

100 requests per hour

BASIC Plan

1,000 requests per hour

PREMIUM Plan

10,000 requests per hour

ENTERPRISE Plan

Unlimited requests

📚 SDK & Libraries

Use our official SDK for easier integration:

JavaScript/TypeScript

npm install @shipex/sdk import { ShipexClient } from '@shipex/sdk'; const client = new ShipexClient({ apiKey: 'your-api-key' }); const order = await client.orders.create({ recipientName: 'John Doe', recipientPhone: '+201234567890', address: '123 Main St', city: 'Cairo', price: 500 });

Browser (CDN)

<script src="https://cdn.shipex.com/sdk/shipex.min.js"></script> <script> const client = new ShipexClient({ apiKey: 'your-key' }); </script>

💡 Common Use Cases

1. Calculate Shipping Rate

POST /shipping/calculate-rate { "origin": { "city": "Cairo" }, "destination": { "city": "Alexandria" }, "weight": 2.5, "serviceType": "EXPRESS", "codAmount": 500 }

2. Create Order

POST /orders { "recipientName": "John Doe", "recipientPhone": "+201234567890", "address": "123 Main Street", "city": "Cairo", "price": 500, "codAmount": 500, "weight": 2.5 }

3. Generate Shipping Label

POST /labels/generate { "orderId": "order-uuid", "format": "A4" }

4. Track Order (Public)

GET /public/track/SHX123456789 // No authentication required!

5. Validate Address

POST /shipping/validate-address { "address": "123 Main Street", "city": "Cairo", "country": "Egypt" }

📋 Available Endpoints

Here's a quick overview of our main API endpoints:

Orders

POST /orders - Create order
GET /orders - List orders
GET /orders/:id - Get order
PUT /orders/:id/status - Update status

Shipping

POST /shipping/calculate-rate - Calculate rate
POST /shipping/validate-address - Validate address
GET /shipping/autocomplete - Address autocomplete
GET /shipping/cities - List cities

Labels

POST /labels/generate - Generate label
POST /labels/generate/bulk - Bulk generate
GET /labels/order/:id - Get label
GET /labels/order/:id/download - Download PDF

Tracking (Public)

GET /public/track/:trackingNumber - Track order
GET /track/:trackingNumber - Track order (alias)

Rate Limiting

GET /rate-limit/usage - Get quota usage
GET /rate-limit/stats - Get statistics
